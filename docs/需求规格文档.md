## 极客风格 Markdown 笔记编辑器 – 最终需求文档

### 1. 核心功能
- 单页面应用，三栏布局：左侧笔记列表 | 中间编辑器 | 右侧实时预览
- 数据存储在浏览器本地（localStorage / IndexedDB），持久化保存
- 完全离线可用，无需后端

### 2. 视觉与交互风格（极客风）
- **配色**：深色背景（终端黑），普通文本银灰色，代码荧光绿高亮
- **字体**：等宽字体（如 Fira Code、Monaco）
- **元素**：无圆角，硬边框，终端风格加载动画/光标闪烁
- **右键菜单**：自定义样式，与整体风格统一

### 3. 笔记列表（左侧栏）
- **显示**：只显示笔记标题
- **排序**：默认按最后修改时间倒序（最新在前）
  - 排序控件位于右键菜单，提供“按创建时间”、“按修改时间”、“按标题”排序
- **搜索**：实时全文搜索（输入时过滤列表）
- **新建笔记**：
  - “新建笔记”按钮位于列表顶部
  - 点击后，在列表顶部出现一个可编辑的文本框（内联）
  - 用户输入标题后，回车 或 文本框失去焦点 均触发创建
  - 按 Esc 不取消创建（即仍保留文本框，允许继续输入）
  - 创建后自动打开新笔记（编辑器显示空内容）
- **笔记操作**（右键菜单）：
  - **删除**：确认后删除笔记
  - **重命名**：在列表项内联编辑标题（回车/失焦确认，Esc 取消）
  - （MVP 阶段仅这两项，其他如复制、导出单条等作为扩展）
- **标签管理**：
  - 笔记数据模型中包含标签字段（数组）
  - 系统自动统计所有笔记中出现过的标签，并展示在左侧栏某个区域（例如列表上方或下方）
  - 点击任意标签，列表过滤出包含该标签的笔记；再次点击取消过滤（或提供清除筛选按钮）

### 4. 编辑器（中间栏）
- **Markdown 支持**：完整语法，包括代码块、表格等
- **快捷键**：标准 Markdown 快捷键（如 `Ctrl+B` 加粗、`Ctrl+I` 斜体），不支持自定义（扩展）
- **行号**：显示行号
- **自动保存**：内容变化实时写入本地存储
- **编辑器与预览区滚动同步**：编辑区滚动时，预览区自动滚动到对应位置

### 5. 预览区（右侧栏）
- **实时渲染**：编辑器内容变化立即更新预览
- **支持扩展语法**：
  - 代码高亮（使用荧光绿配色）
  - 数学公式（LaTeX）
  - 流程图（如 Mermaid）

### 6. 导入/导出功能
- **导出**（当前笔记）：
  - 提供三个独立按钮：导出 HTML、导出 PDF、导出 Markdown
  - 一个“聚合导出”按钮，点击后同时生成并下载三种格式的文件（可打包为 ZIP 或依次下载）
- **导入**（从本地文件）：
  - 拖拽 Markdown 文件到页面任意位置即可导入
  - 读取文件名作为笔记标题，文件内容作为正文
  - 导入后自动创建新笔记并保存

### 7. 响应式与移动端支持
- **三栏布局在窄屏下自适应**：
  - 屏幕宽度小于某个阈值（如 768px）时，三栏转为堆叠布局（默认显示列表，可切换编辑器/预览）
  - 提供移动端友好的交互（如折叠面板、滑出菜单）
  - 确保所有功能在移动设备上可用

### 8. 技术实现要点（供开发参考）
- **前端框架**：可选 React/Vue 或原生 JS（根据团队偏好）
- **Markdown 解析**：使用成熟的库（如 marked、remark）并集成代码高亮（如 Prism.js 或 highlight.js）
- **PDF 导出**：可将 HTML 内容通过库（如 jspdf）转换，或使用浏览器打印功能生成 PDF
- **存储**：localStorage 适合小量笔记，若笔记数量大可考虑 IndexedDB
- **滚动同步**：计算编辑区滚动比例，映射到预览区对应元素位置
