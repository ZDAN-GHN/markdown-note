## 项目介绍
极客风格 Markdown 笔记编辑器，基于 Cursor 快速完成原形开发，基于 npm 构建的、无后端的纯 Vue3 项目，具体技术选型可查看 [技术方案文档](./docs/技术方案文档.md)

## 快速开始

确保 nodejs 版本不低于 20.18.0，在项目根路径下执行如下命令：
```
npm insatll
npm run dev
```
